# Íconos web

Favicon, íconos de app y manifiesto, generados a partir del símbolo pequeño.

- `head-snippet.html`: etiquetas listas para pegar en el `<head>`.
- `site.webmanifest`: manifiesto para instalar la app.
- `favicon.ico`, `favicon.svg`, `favicon-16/32/48.png`: pestaña del navegador.
- `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `maskable-512.png`: pantalla de inicio.
- `meloxo-symbol-*.svg`: variantes del símbolo (un color, cuadrado, ícono de app).

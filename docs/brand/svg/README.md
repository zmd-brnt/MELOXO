# Archivos maestros (SVG)

Fuente de verdad del logo. Todo está en trazos: no dependen de ninguna fuente instalada.

Cada versión (`symbol`, `horizontal`, `stacked`, `wordmark`) existe con estos sufijos:

| Sufijo | Uso |
|---|---|
| sin sufijo | Tinta `#141317` sobre fondo claro |
| `-color-dark` | Rosa y papel sobre tinta. Versión principal |
| `-color-light` | Rosa y tinta sobre papel |
| `-reversed` | Papel sobre tinta, un solo color. Agujeros 1 unidad más grandes para compensar que lo claro se ve más grueso |
| `-black`, `-white`, `-mono-141317` | Un color, exportados. Solo `horizontal` y `stacked`; los del símbolo están en `../web/` |

`meloxo-symbol-small.svg` es un dibujo simplificado para menos de 32 px.

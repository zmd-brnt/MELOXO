# Pantallas

Una pantalla por ruta. Las rutas van en inglés y el texto en español.

Los casetes viven en `TapeDetail.tsx`, `TapeCreate.tsx` y `TapeInvite.tsx`. Reordenar funciona arrastrando y con los botones
subir y bajar, que son la vía de teclado. Si otra persona cambió el casete, el servidor responde 409 y la pantalla recarga.

## Subcarpetas

- [`composer/`](composer/README.md): vistas de Compositor.
- [`admin/`](admin/README.md): vistas de Administrador.

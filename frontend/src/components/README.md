# Componentes

Piezas que se usan en más de una pantalla.

El desorden es solo para contenido. Menús, búsqueda y reproductor van rectos.

| Componente | Para qué sirve |
|---|---|
| `AppShell` | Marco de la app: tres paneles y reproductor |
| `Sidebar` | Navegación lateral, que en teléfono se vuelve pestañas |
| `SearchBox` | Buscador de arriba |
| `NoticesBell` | Campana de avisos |
| `Icon` | Íconos |
| `Note` | Papel rasgado, con cinta adhesiva si se pide |
| `Cover` | Portada, con un degradado propio de cada pista si no tiene |
| `SongRow` | Fila de una canción |
| `AddSong` | Agregar una canción a un casete o a una playlist |
| `Attribution` | Crédito de artista, Jamendo y licencia. La licencia de Jamendo lo exige |
| `ArtistLinks` | Enlaces de un artista |
| `Tape` | Dibujo del casete |
| `TapePile` | Pila de casetes |
| `TapeSide` | Un lado del casete con sus pistas |
| `DedicationEditor` | Escribir una dedicatoria |
| `InvitePanel` | Crear y compartir enlaces de invitación |
